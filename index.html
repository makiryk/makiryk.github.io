Web Developer ／ 個人開発

AI や Google のサービスを組み合わせて、いつもの作業をラクにするしくみを個人で作っています。

最近は、Alexa から Gemini に質問できるスキルや、Claude Code と Gemini が作業を任せ合うツールを作りました。

作ったもの

  • ジェミニ

    Alexa に話しかけた質問に Gemini が答えて、そのまま読み上げる Alexa スキル。続けて質問もできます。

    Alexa · Gemini API

  • ai-handoff

    Claude Code と Gemini（Antigravity CLI）が、得意な作業を互いに任せ合うしくみ。使用量を見て振り分けも決めます。

    Claude Code · Gemini · Python

  • darts-crowd-map 開発中

    ダーツのお店を地図で探して、混み具合の予測を見られる Web アプリ。追加費用ゼロで動かすことを決まりにしています。

    Web · 地図

  • Android Auto ヘッドユニット

    USB でつないだスマホの Android Auto を、PC 上の車載ナビ画面に映す Windows 用ランチャー。

    Python · Windows

できること

  • AI といっしょに開発

    Claude や Gemini を開発の相棒にして、アイデアを小さく早く形にします。

  • Google のサービスをつなぐ

    Gmail・カレンダー・スプレッドシートなどをつないで、転記や確認の手間をなくします。

  • いつもの作業をラクにする

    毎日くり返している作業を見つけて、ボタンひとつで終わるしくみにします。
